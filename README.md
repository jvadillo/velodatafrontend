# Ride Compare

Quiero que desarrolles una aplicación en la que un usuario puede subir varios archivos GPX de recorridos hechos en salidas con bicicleta de carretera y la aplicación sea capaz de detectar tramos comunes entre los archivos GPX y mostrar la diferencia de rendimiento en cada uno de los tramos.
